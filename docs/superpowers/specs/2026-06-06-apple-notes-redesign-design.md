# Puck Todo Apple Notes 风格美化设计

## 目标

将 Puck Todo 的原生前端升级为 Apple Notes 式极简纸感界面：安静、清晰、适合个人长期使用，同时保留现有待办创建、编辑、完成、删除、月份筛选等功能。

## 范围

- 保留现有 Python API、SQLite 数据结构和 `static/app.js` 的主要业务流程。
- 重点修改 `static/style.css`，必要时轻量调整 `static/index.html` 和 `static/app.js` 中的展示文案或按钮可访问标签。
- 不引入前端框架、不引入构建步骤、不新增外部依赖。
- 不提交 `.superpowers/brainstorm/` 生成的可视化临时文件。

## 视觉方向

采用用户选择的 B 方案：Apple Notes 极简纸感。

- 背景从蓝色玻璃渐变改为温暖的纸面底色，使用细微纹理和浅层次区分区域。
- 卡片减少强阴影和高饱和玻璃效果，改为细分隔线、柔和纸面、轻微内阴影。
- 文字层级更像 Apple 系统应用：大标题克制、列表信息密度更高、辅助文本更淡。
- 优先级颜色降低饱和度，避免警告色过度抢眼，但保留紧急程度识别。
- 交互反馈保持轻量：hover、active、focus 明确但不喧宾夺主。

## 页面结构

- 顶部保留每日引语和月份选择，但视觉上更像笔记应用的标题区。
- 新增待办区域保留表单字段，布局改为更自然的纸面编辑块。
- 未完成与已完成列表保留双列桌面布局，移动端保持单列。
- 待办项从浮动卡片改为纸面列表行，降低装饰感，提高扫描效率。
- 编辑弹窗使用同一纸面语言，避免与主界面风格割裂。

## 可访问性与响应式

- 保留表单 label、dialog 语义、toast 状态提示。
- 为按钮、输入框和列表项提供清晰 focus 样式。
- 小屏下保持 1 列布局，月份选择和操作按钮不溢出。
- 遵守 `prefers-reduced-motion`，减少动效用户不应看到过渡动画。

## 验证

- 运行现有 Python 测试，确认核心逻辑和编辑 UI 测试不回归。
- 启动本地服务并用浏览器或 HTTP 请求确认页面可访问。
- 做基础响应式检查，重点看桌面与窄屏下表单、列表、弹窗是否可用。
