# 倒数日频次功能设计

## 目标

在现有“倒数日”页面中支持三类事件：

- 一次性事件：沿用当前逻辑，未来显示“还有 X 天”，过去显示“已过去 X 天”，当天显示“今天”。
- 每月重复：例如“每月 15 号发工资”，显示“还有 X 天”或“今天”，并标注“每月 15 日”。
- 周年纪念日：例如“第一次接吻”，主状态显示“已过去 X 天”，同时显示“离 N 周年还有 X 天”或“今天是 N 周年”。

## 数据模型

在 `countdowns` 表上追加字段：

- `event_type`: `once`、`monthly`、`anniversary`，默认 `once`。
- `repeat_month`: 周年纪念日使用，范围 `1-12`。
- `repeat_day`: 每月重复和周年纪念日使用，范围按月份合法日期校验。

保留 `target_date`：

- `once`: 目标日期。
- `monthly`: 用当前日期所在年份拼出一个合法日期，主要兼容旧字段。
- `anniversary`: 原始纪念日起始日期。

## 表单

倒数日页新增“类型”选择：

- 一次性：显示日期输入。
- 每月：显示“每月几号”数字输入。
- 周年：显示起始日期输入。

## 展示规则

所有日期差按本地自然日计算，不按 24 小时滚动计算。

每月重复事件计算下一次发生日：

- 如果本月该日未到或就是今天，使用本月。
- 如果已经过去，使用下个月。
- 该月没有对应日期时，用该月最后一天，例如 31 号在 2 月按 2 月最后一天。

周年纪念日计算下一次周年：

- 从 `target_date` 得到原始年份、月份、日期。
- 今年周年未到或就是今天，使用今年；否则使用明年。
- 周年数按下一次周年年份减原始年份计算。

## API

继续使用现有端点：

- `GET /api/countdowns`
- `POST /api/countdowns`
- `DELETE /api/countdowns/:id`

`POST` 接收并校验 `event_type`、`target_date`、`repeat_month`、`repeat_day`。
